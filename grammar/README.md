## What a topic contains

Each topic is split into numbered sections, each one self-contained enough to read on its own:

```
01-reported-speech/
  README.md              the hub — what the topic is, and where to start
  01-basics.md           …
  08-special-cases.md    numbered sections, each a complete sub-topic
  catalog/               a dictionary, where the topic has a word list worth one
    README.md            A–Z index
    browse.html          searchable, click any entry to hear it
    01-neutral.md …      grouped entries
    data/                the same entries as JSON
```

Every rule is demonstrated with a real sentence, contested points say so instead of pretending the textbook rule is universal, and each section ends with practice items and an answer key.

## Why reported speech first

It is the topic where the most learners with otherwise good English still produce sentences that are unmistakably wrong — ✗*She asked where was I*, ✗*He suggested me to leave* — because it requires several changes to happen in coordination rather than one rule to be applied. It also has a genuine word list behind it (the reporting verbs), which is where most references stop just as the useful part begins.
